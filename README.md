# doctorasma.com

Website for the Doctor Asma YouTube channel (youtube.com/@DoctorAsma), served by GitHub Pages.

- `index.html`: home page. The "Latest videos" grid reads `videos.json` (`[{"id": "...", "title": "...", "url": "..."}]`, newest first), which the laptop's `vlog upload` updates.
- `privacy.html`: privacy policy (used by the Google sign-in screen and the YouTube API audit).
